## 数据流

### 新闻抓取流程

```
RSSHub → rss.ts → db.ts → search.ts (索引向量)
                ↓
         eventEngine.ts (事件识别)
```

### 用户阅读流程

```
User → NewsCard → api.ts → Express → db.ts → SQLite
         ↓
    EntityTag → ai.ts → Claude Code
         ↓
    Timeline → search.ts → sqlite-vec
```

### 搜索流程

```
Query → search.ts → FTS5 (关键词)
              ↓
         sqlite-vec (向量)
              ↓
         混合排序 → 结果
```

## 核心模块说明

### 1. RSS 模块 (rss.ts)
- 从 RSSHub 抓取新闻
- 解析 XML，提取标题、内容、图片
- HTML 实体解码
- 生成唯一 ID

### 2. AI 模块 (ai.ts)
- 调用 Claude Code CLI
- 实体抽取 (人名、组织、地点等)
- 时间线生成
- 事件识别

### 3. 数据库模块 (db.ts)
- SQLite 操作封装
- 文章增删改查
- 事件管理
- 抓取日志

### 4. 搜索模块 (search.ts)
- sqlite-vec 向量搜索
- FTS5 全文搜索
- 混合搜索策略
- 向量索引管理

### 5. 事件引擎 (eventEngine.ts)
- 识别相关新闻
- 聚合同一事件
- 管理事件生命周期

### 6. 调度器 (scheduler.ts)
- 定时抓取 RSS
- 批量处理新闻
- 自动索引向量

## 技术选型理由

### SQLite + better-sqlite3
- 轻量级，无需额外服务
- 支持 sqlite-vec 扩展
- 支持 FTS5 全文搜索
- 单文件，易于备份

### sqlite-vec
- 本地向量存储
- 无需外部向量数据库
- 支持相似度搜索

### Claude Code CLI
- 本地运行，无需 API Key
- 支持复杂推理任务
- 可搜索本地数据库

### RSSHub
- 统一 RSS 格式
- 支持多种新闻源
- 可自托管
