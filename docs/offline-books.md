# 客户端书籍离线阅读

Desktop 和 Mobile 在书架的每本书下提供下载，整卷章节、搜索索引和相关图片完整保存并通过校验后显示“可离线”。点封面照常打开阅读；下载时可取消、失败时可重试，点击“可离线”可查看大小和删除本机下载。

已下载的书独立于云端收藏保留。断网重启时，书架不等待云端请求或账号网络初始化即可展示可访问的本机下载。删除下载不会删除云端收藏，移出云端书架也不会自动清理下载。

Web 不提供离线下载，不注册离线 Service Worker。首页、账号中心、阅读器不新增离线入口，没有独立管理页。范围仅限书籍，听书和 AI 等联网能力、报刊 PDF 整期下载不在本次范围。

## 存储与权限

共享下载和完整性校验位于 `@jojo/content`。Desktop 入口显式启用共享前端中的离线能力，通过 IndexedDB 保存；Mobile 使用应用 document 目录。两端自带应用外壳，无需 Web 离线缓存。

公共书籍可在退出登录后保留；受限书籍按账号隔离，退出或切换账号时清理不再可访问的副本。离线会话恢复只允许打开归属匹配的已下载书籍，不赋予联网 API 或新下载权限。清除应用数据会删除本机下载。

本功能不依赖数据库迁移，不修改服务端或阅读器“更多”菜单。

## 验证

- `frontend/packages/content/tests/offline-books.test.ts`：完整资源保存、断网重新打开、索引与图片校验、失败重试、取消与删除、账号隔离。
- `frontend/web/tests/bookshelfOffline.test.tsx`：云端不可用时展示下载、书籍 ID 去重、下载状态与删除操作。
- `frontend/web/tests/offlinePlatform.test.ts`：Web 不初始化下载、读取离线文件或恢复离线身份。
- `frontend/mobile/src/offline/bookshelf.test.tsx`、`repository.test.ts`：书架离线打开与操作、持久文件存储。
- 现有书籍阅读、公共封面、账号会话和听书测试继续回归。

发布前仍需在 Android、iOS 和桌面安装包上验收后台切换、断网重启和系统存储清理；组件和存储测试不替代真机验收。
