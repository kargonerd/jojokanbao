# 移动端 PDF 阅读器界面设计

Mobile 的报刊阅读器打开的是整期 PDF 的固定版式页面，没有可选取的文字层。界面按「页面级」能力设计：沉浸阅读、页码定位、缩略图跳转、整页批注、下载与缓存状态、离线失败，共 7 屏。

设计稿：`JOJO阅读器 · PDF阅读体验重设计`（Ardot，可编辑）
https://ardot.tencent.com/file/732890931147422

## 现状与问题

`frontend/mobile/src/screens/ReaderScreen.tsx` 用 `WebView` 直接加载 archive 网页版阅读器，只靠 `readerBridge.ts` 注入脚本隐藏网页页头、转发页码。因此固定 58px 页头、页码只出现在标题副行、加载态是通用 `ActivityIndicator`、错误态是全屏文案，没有页码定位、缩略图、目录、设置、批注入口——手感是网页的，不是手机的。

## 内容形态带来的边界

内容是不可重排的整页版面，所以下列能力不做，不是暂缓：

- 划词高亮、选区两端手柄、复制、加粗：没有文字层。
- 改字号、首行缩进、纸张底色：改动不了固定版式的排版。
- 版面目录（标题到页码的映射）：PDF 无书签，只能得到总页数。

批注只做到页面级：整页笔记、书签、已读标记，页边红竖条加页码角标。

## 七屏

| 屏 | 内容 |
| --- | --- |
| 01 沉浸式阅读 | 无 chrome，仅状态栏、页图、底部细进度与 `12 / 48` |
| 02 工具层展开 | 顶部刊名、期号与页码；底部深色控件条：上一页、页码、下一页、缩略图入口、红色 scrubber |
| 03 缩略图与跳转 | 全页缩略图网格，当前页红框与「当前」标签；底部跳转到指定页、前往、总页数 |
| 04 页级批注与标记 | 已批注页左侧红竖条、页码角标；底部页级工具条（书签、已读、笔记、导出）与批注输入条 |
| 05 阅读设置 | 翻页方式（分页 / 连续滚动）、单双页、eInk 灰阶、屏幕常亮、允许横屏、触感反馈、恢复默认 |
| 06 载入中 | PDF 下载进度：顶部进度条、骨架页、百分比、版本与页数、后台继续下载与取消 |
| 07 离线与失败 | 本期未下载时的说明、下载本期与看缓存往期、本机已缓存期数提示 |

设置项与 `frontend/mobile/src/store/mobileStore.ts` 现有字段一一对应；配色取 `frontend/mobile/src/theme/tokens.ts`（`red #8b1a1a`、`ink #202020`、`muted #68645f`、`canvas #f4f4f2`），eInk 走灰阶。

## 待定

- 版面目录：若服务端产出 page-map（期次、文章标题、起始页），第 4 类入口可加回目录形态。当前无数据来源。
- 批注数据模型：设计按「期次 + 页码 + 文本」设想，与现有 `reader_annotations`（锚定段落）不兼容，需先定是否复用桌面批注。
- 离线中间态：缓存过期、下载中断是否需要单独一屏。

## 落地路线

正文渲染继续走现有 PDF 链路，原生层先接管页码 scrubber、缩略图与按页跳转、页级批注、下载进度与缓存提示。缩略图需要渲染产物（服务端出图或本机首次渲染缓存），未产出前该屏不可用。

## 验证

真机验收 Android 与 iOS 的翻页手感、深色夜间环境可读性、断网打开缓存、下载中断后续传。缩略图在低端机上的首屏耗时需单独测量，超时降级为纯页码定位。
