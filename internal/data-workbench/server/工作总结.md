## 二、技术实现要点

### 文件名匹配器 (`file_name_matcher.py`)

```python
# 支持的中文数字转换
chinese_year_to_arabic("一九五二")  # → "1952"
chinese_month_to_arabic("十一")     # → "11"
chinese_day_to_arabic("二十三")     # → "23"

# 格式验证
apply_rule(filename, pattern, extractor_code, pub_type='journal')
# 期刊: 必须是6位纯数字 (yyyyNN)
# 报纸: 必须是8位纯数字 (yyyyMMdd)
```

### 预估时间算法

```javascript
// 滑动平均平滑预估时间
const pagesPerSecond = current_page / elapsed;
const remainingPages = total_pages - current_page;
const estimatedRemaining = remainingPages / pagesPerSecond;

// 保留最近10个数据点求平均，避免跳动
etaHistory.push(estimatedRemaining);
if (etaHistory.length > 10) etaHistory.shift();
const smoothedEta = etaHistory.reduce((a, b) => a + b, 0) / etaHistory.length;
```

### 新报刊配置生成路径

```
OneDrive根目录
├── {PUB_CODE}/           # 完整PDF (processed_path)
│   └── {year}/
│       └── {yyyyNN}.pdf
└── internal/{PUB_CODE}/  # 拆分PDF (split_path)
    └── {year}/
        └── {yyyyNN}/
            └── page_001.pdf
```

## 三、API接口

### 新报刊相关
| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/publications` | POST | 创建新报刊配置 |
| `/api/publications/<code>/image` | POST | 上传封面图片 |
| `/api/publications/<code>/generate-vue` | POST | 生成Vue代码 |
| `/api/publications/<code>/apply-changes` | POST | 应用所有变更 |
| `/api/fetch-baike` | POST | 从维基百科获取报刊简介 |

### 文件处理相关
| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/scan-files` | POST | 扫描目录（支持子目录） |
| `/api/apply-custom-rule` | POST | 测试AI规则（含类型校验） |
| `/api/generate-iteration-prompt` | POST | 生成迭代AI prompt |
| `/api/start-staging` | POST | 启动预处理任务 |
| `/api/progress/<task_id>` | GET | SSE进度流 |
| `/api/health` | GET | 服务器健康检查 |
