# 纪念焕新开场

LaunchCommemoration 仅在新版首页首次访问时播放，不占据首页布局，也不提供常驻纪念条或重播入口。画面沿用白纸、朱红和现有宋体字栈，无图片、音频或新增依赖。

画面保留纪念标题、1976—2026 起止年份、完整诗句与出处、JOJO 看报焕新升级及必要的播放按钮。年份紧凑排在“50”与“周年”下方，桌面为 18px，手机为 12–13px，不使用横跨纸面的长分隔线。移除“纪念专页”、重复日期、重复标题和纸面页眉页脚小字；右上角仅显示“跳过动画”，阶段提示仅供辅助技术读取。

两段诗句的出处只展示“毛泽东《作品名》”，不展示创作年份，并在各自诗句下方右对齐。

焕新诗句与出处先作为整体在纸面正中呈现。品牌和按钮保留最终布局空间，以其高度的一半补偿诗句的位置；第 16 秒品牌出现并开始变彩时，用 3 秒 transform 位移动画平缓上移，不逐帧改变布局高度。只在初次显示和尺寸变化时通过 ResizeObserver 测量，离开页面时断开监听；暂停和减少动态效果同样覆盖位移动画。文字显影使用透明度与轻微位移，避免动画模糊滤镜；翻页与位移元素的合成提示随组件移除。

- 仅北京时间 2026 年整个九月首次进入首页时触发：9 月 1 日 00:00 起，至 10 月 1 日 00:00 前。使用显式 +08:00 时间边界，与访客所在地时区无关。
- Beta 站不播放：复用 isBetaChannel()，在 beta.jojokanbao.cn 域名或 VITE_RELEASE_CHANNEL=beta 构建中直接跳过，不改变页面色彩或写入已播放记录。
- 同一浏览器保存已播放记录后只播放一次，刷新、重新进入首页或重启浏览器均不重播。保留 localStorage 的 jojo:commemoration:1976-2026:seen 标记；旧版本已看过的访客不会因本次修改再次播放。记录按网站和浏览器保存，不跨设备或账号同步；清除网站数据可能再次播放。存储无法读取或写入时直接跳过，避免反复出现。
- 全长 26 秒：第一页为 7 秒，完整纪念诗句显影后停留约 2 秒；第 7 秒开始翻页，用 3.2 秒完成翻转。第二页第一句在第 8.6–10.6 秒显现，第二句在第 10.8–12.8 秒显现，出处随后出现；诗句保持黑白居中至第 16 秒。随后“JOJO 看报 · 焕新升级”淡入，诗句平缓上移，同时用 8 秒恢复色彩。“进入新版”按钮在品牌文字显示后出现，彩色画面停留至最后 0.8 秒淡出并自动返回首页。可随时跳过或按 Escape 退出，也可暂停；切到后台会暂停计时与动画。翻页、变彩与结束使用独立计时节点。
- 纪念画面和翻页全程黑白灰，纪念纸面中的数字与线条本身也使用灰黑色，避免提早出现红色。第二段诗句完整呈现并停留后，焕新纸面、标志与首页同步从灰度缓慢恢复朱红和原有色彩，采用连续显色，不使用分割画面的铺色边界。暂停时颜色过渡也暂停；跳过、播放结束或离开首页时清理临时色彩状态，不影响之后的正常阅读。
- 系统开启「减少动态效果」时不自动播放；播放途中切换此设置时展示静态内容，保留退出按钮。不支持原生 dialog.showModal() 的旧 WebView 不播放。
- 沿用现有 VITE_ENABLE_PLATFORM_REDESIGN 发布开关；旧版 Archive 首页和阅读深链接不触发开场。

## 文案出处

- 「天若有情天亦老，人间正道是沧桑。」毛泽东《七律·人民解放军占领南京》（1949 年），见[人民网引录](https://theory.people.com.cn/n1/2021/0727/c40531-32171877.html)。
- 「雄关漫道真如铁，而今迈步从头越。」毛泽东《忆秦娥·娄山关》（1935 年），见[共产党员网引录](https://www.12371.cn/2023/12/16/ARTI1702690696933558.shtml)。

本地预览：运行 pnpm --filter @jojo/web dev。开发模式暂时跳过“只播放一次”限制，每次刷新或重新进入首页均可重播，不读取、清除或写入已播放记录。日期、Beta 排除和减少动态效果的规则仍然生效；生产构建保持同一浏览器只播放一次。

验证：pnpm --filter @jojo/web test -- tests/launchCommemoration.test.tsx tests/homeLibrary.test.tsx tests/app.test.tsx，另运行 Web 的 typecheck、build 与 verify:build。
